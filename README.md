# file handling
My repository for file handling scripts, a very common task in most programming workflows, created during studies. The Python part is rather useless, as I just implemented some wrapper functions for existing ones to give them my own name. I would not recommend doing it this way, but there it is. The ImageJ Macro code is more useful, as it does not have the package abundance that Python has (nowhere near it), and is more janky overall. So, definitely check them out if you want to copy some file handling code for your own ImageJ Macro / Fiji code :).

The initially intended purpose is as a `git submodule` within my other git repositories, simplifying the usual file handling tasks.

Currently implemented programming languages:
- python (`.py`)
- ImageJ Macro (`.ijm`) - just enough to fit my Fiji needs, not very sophisticated / extendable.
